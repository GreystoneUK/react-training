# react-training-playground

A small full-stack JavaScript training project with a React + Vite frontend and an Express mock API backend.

## Getting started

Open two terminals:

1. Start the API
   ```bash
   cd server
   npm install
   npm start
   ```
2. Start the client
   ```bash
   cd client
   npm install
   npm run dev
   ```

The client proxies `/api` to `http://localhost:4000` during development.
